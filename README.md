## 🛠 Технології та рішення

- **Чисті HTML5 та CSS3:** Верстка виконана суто за допомогою чистих стандартизованих технологій без використання третіх бібліотек та UI-фреймворків.
- **Mobile First:** Базове позиціонування побудовано для екранів від 375px з подальшим використанням медіа-запитів (`min-width: 768px` та `min-width: 1280px`).
- **CSS-змінні (`:root`):** Усі кольори, типографіка та сітки винесені у дизайн-токени для легкого перевикористання та гнучкості.
- **Чистий CSS без JS:** Відкриття/закриття мобільного бургер-меню та фільтрація списку робіт реалізовані за допомогою CSS псевдокласів `:checked` та селекторів зв'язку.
- **Accessibility & Optimization:** Семантична структура, коректні ARIA-атрибути, підключення шрифтів Google Fonts із `font-display: swap` та використання WebP-сумісних зображень із `loading="lazy"`.
